* Maneiras de configurar o fundo do site:

    No css:

  1. Cor única:

            background-color: skyblue;

  2. Cor com efeito degradê:
        
            background-image: linear-gradient(to bottom, yellow, red);

  3. Com imagem externa:

            background-image: url(images/pattern003.png); /*A imagem se repetirá automaticamente, em seu tamanho padrão;*/

  4. Definindo tamanho da imagem externa:

	    background-size: 100px 100px;


  5. Repetição de imagem externa:

	    background-repeat: repeat; /*Repetição padrão*/
	    background-repeat: repeat-x; /*repetição na horizontal*/
	    background-repeat: repeat-y; /*repetição na vertical*/
	    background-repeat: space; /*repetição com espaço entre as imagens*/
	    background-repeat: round; /*Repetição arredondada*/
	    background-repeat: no-repeat; /*Sem Repetição da imagem*/	
 
  6. Posição da imagem:

	    background-position: coluna linha;

	Sempre vem primeiro a coluna depois a linha. Colunas podem ser left, right e center e linhas podem ser top, bottom e center. Ex:

	    background-position: left top;
 
  6. Tamanho da imagem:

	background-size: 100% 100%; //Forma burra  de preencher uma imagem de fundo na tela toda, pois a distorce..
	Ex:
			/* Keyword values */
		background-size: cover; /*Cobre 100% da imagem na tela*/
		background-size: contain; /*Contem 100% da imagem na tela*/

			/* One-value syntax */
	/* the width of the image (height becomes 'auto') */
		background-size: 50%;
		background-size: 3.2em;
		background-size: 12px;
		background-size: auto;

			/* Two-value syntax */
	/* first value: width of the image, second value: height */
		background-size: 50% auto;
		background-size: 3em 25%;
		background-size: auto 6px;
		background-size: auto auto;

			/* Multiple backgrounds */
		background-size: auto, auto; /* Not to be confused with `auto auto` */
		background-size: 50%, 25%, 25%;
		background-size: 6px, auto, contain;

			/* Global values */
		background-size: inherit;
		background-size: initial;
		background-size: revert;
		background-size: revert-layer;
		background-size: unset;

* View-Height:

  1. 100vh:
	
	   É 100% da viewport. E quando falamos em web responsiva, a viewport é a área visível pelo usuário de uma página web. O conteúdo que não está visível, só pode ser visto com um scroll, por exemplo.
		
	   Obs:

		Ao invés de botar o { height: 98vh; } para não aparecer a barrar de rolagem, basta colocar normalmente { height: 100vh; } e acrescentar a declaração { margin: 0px; } no interior do seletor body. Assim não é preciso ficar testando os valores de vh para cada navegador, devices e suas variações.

		O que faz aparecer a barra de rolagem é o body que vem com uma margem padrão. Ao colocar o height do body, que está com a imagem, para 100% da área de visão, o navegador acrescenta mais um espaço em branco que é essa margem, portanto a rolagem aparece, porque o body passa a ocupar 100% da área do navegaor + margem. Depois é só centralizar a imagem com { background-position: center center; }

	   

* Centralização Vertical de Caixas:

	1. Posicionamento do elemento pai tem q ser relativa, postition: relative;
	2. Se o pai for uma box (div, section, article..) ela é default position relative
	3. Já o posicionamento do próprio elemento deverá ser absoluto position: absolute;
	4. Quando colocamos uma posição absoluta, podemos usar as propriedades left e top
	5. Se colocarmos left: 50%; e top: 50%; ele ficará alinhado no centro do elemento pai com a ponta esquerda de cima dele
	6. Para alinharmos centro com centro, utilizaremos a propriedade transform com a função translate(), transform: translate(-50%,-50);
	7. Passamos os parametros -50% e -50% para movermos pra esquerda e cima

	15. Tabelas Responsivas

		A dica é:
			Indenpedente do tamanho o browser ira expremer a tabela e quando vazar, ele coloca uma rolagem lateral
		
		Para fazer, vc deve envolopar sua tabela em uma div, criar uma classe ou id para ela e no css colocar: overflow-x: auto;. Para rolagem horizontal.

		Anotação:

		Algumas tabelas às vezes ficam lateralmente muito grandes, fazendo com que o conteúdo acabe vazando em telas pequenas (celulares)... Resultando numa página com rolagem lateral, que é indesejada quando trabalhamos com responsividade.

		Para resolver isso, devemos tornar a tabela da sua página responsiva. A primeira coisa que devemos fazer para ajeitar a formatação da nossa tabela é envelopar a tag <table> (toda a tabela) com uma <div>, posteriormente identifique essa div com um id ou class (nome: container).

		Em seguida, abra um seletor CSS para a div/class que acabamos de configurar (div.container {...} ) e insira a seguinte declaração:

		div.container {
			overflow-x: auto;
		}

		O overflow é uma propriedade de estilo do CSS utilizada para tratar conteúdos que ultrapassam os limites de um elemento. O objetivo do overflow é fazer com que conteúdos muito grandes possam caber dentro de uma página através do uso de barras de rolagem.

		Apenas com essa configuração já é suficiente para tornar a nossa tabela responsiva. Na prática, quando essa tabela for aberta numa tela com uma largura inferior à mesma, ela será "cortada" e exibida dentro de uma caixa com barras de rolagem horizontal, evitando o vazamento. 

		Toda essa adaptação ocorre de forma automática, isso se deve ao fato de usarmos o valor "auto". Esse valor (auto) exibe barras de rolagem somente quando necessário, somente quanto a largura do container se torna insuficiente para exibir o elemento.

		PROPRIEDADE - OVERFLOW:

		Usamos a propriedade " overflow-x ", entretanto existem também o " overflow-y " e o " overflow ". Segue uma descrição de cada um deles:

		overflow-x - A propriedade CSS "overflow-x" é usada para definir o que deve ser mostrado quando o conteúdo transborda dos extremos esquerdo e direito de um elemento em bloco (eixo horizontal).

		overflow-y - A propriedade CSS "overflow-y" define o que deve ser mostrado quando o conteúdo transborda dos extremos superior e inferior de um elemento em bloco (eixo vertical).

		overflow - A propriedade CSS "overflow" é uma abreviação para as propriedades "overflow-x" e "overflow-y" em uma única declaração.

		As propriedades overflow aceitam alguns valores, dentre os principais:

		visible - O valor "visible" exibe o conteúdo que exceder o tamanho do elemento fora da área designada para ele,  (valor padrão).

		hidden - O valor "hidden" simplesmente corta o conteúdo que exceder o tamanho do elemento.

		scroll - O valor "scroll" exibe "a todo momento" barras de rolagem para permitir que o usuário role o conteúdo que exceder o tamanho do elemento.

		auto - O valor "auto" exibe barras de rolagem somente quando necessário (largura ou altura insuficientes)
